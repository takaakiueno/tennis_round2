# テニス ダブルス組み合わせ表(途中変更対応版)

**ここから使えます → https://takaakiueno.github.io/tennis_round2/index.html**

## 概要

大人数でテニスのダブルス(2対2)を回すときに、全ラウンド分の組み合わせ表をまとめて作るツールです。
このツールは、次の4点がなるべく均等になるように組み合わせを決めます。

- 試合数(全員がほぼ同じ回数だけ出場する)
- 休みの間隔(同じ人が続けて休まない)
- ペアを組む相手(同じ人とばかり組まない)
- 対戦する相手(同じ人とばかり当たらない)

さらに、当日の途中で状況が変わっても続きを組み直せます。遅れて来た人の追加、早く帰る人の削除、使えるコートの数の変更、ラウンドの追加に対応しています。終わったラウンドはそのまま残し、それまでの実績を踏まえて残りのラウンドだけを作り直します。

参加者は 1 から始まる番号で表します。当日は各自に番号を割り振って使ってください。番号は最後まで変わりません。

## 使い方

### 1. 条件を入力して「決定」を押す

| 項目 | 入力できる値 |
|---|---|
| 面数 | 1〜3 |
| 人数 | 面数×4 人以上、60 人以下 |
| ラウンド数 | 1〜100 |

「決定」を押すと、約1秒で全ラウンド分の組み合わせが表示されます。乱数を使っているので、押すたびに別の案になります。

上の「決定」は、最初から全部を作り直すためのボタンです。チェックが1つでも入った状態で押すと、すべて消して作り直してよいかの確認が出ます。途中からの変更には、表の中のボタン(手順5・6)を使ってください。

### 2. 組み合わせ表を見る

1ラウンドが1行です。

<thead>
<tr><th nowrap></th><th nowrap>R</th><th nowrap>コート1</th><th nowrap>コート2</th><th nowrap>休み</th></tr>

<tr><td nowrap>☑</td><td nowrap>1</td><td nowrap>3&#8288;・&#8288;7&nbsp;-&nbsp;5&#8288;・&#8288;6</td><td nowrap>1&#8288;・&#8288;9&nbsp;-&nbsp;4&#8288;・&#8288;8</td><td nowrap>2,&nbsp;10</td></tr>
<tr><td nowrap>☐</td><td nowrap>2</td><td nowrap>1&#8288;・&#8288;10&nbsp;-&nbsp;3&#8288;・&#8288;9</td><td nowrap>2&#8288;・&#8288;8&nbsp;-&nbsp;6&#8288;・&#8288;7</td><td nowrap>4,&nbsp;5</td></tr>

- `3・7 - 5・6` は「3番と7番のペア」対「5番と6番のペア」の試合です。
- 「休み」は、そのラウンドに出場しない人の番号です。全ラウンドで休みの人がいないときは、この列は出ません。
- 「印刷」ボタンを押すと、入力欄と表の中のボタンを除いた表を印刷できます。

### 3. 終わったラウンドにチェックを入れる

左端のチェックボックスは、終わったラウンドの目印です。チェックを入れると、その行の文字が薄くなります。

チェックには、もう1つ大事な役割があります。**一番下のチェックの行までが「確定済み」として扱われ、途中変更をしてもそこまでは変わりません。** 作り直されるのは、それより下の行だけです。

チェックが飛び飛びの場合(たとえば 1・2・4 にチェックがあり、3 にはない場合)も、一番下のチェックである 4 までが確定済みになります。

### 4. 途中変更のボタン

チェックを1つでも入れると、一番下のチェックの行のすぐ下に、「メンバー追加・削除」と「面数」の2つのボタンだけの行が出ます。

チェックが1つもないときは、ボタンは出ません。まだ始まっていない段階での変更は、上の入力欄を直して「決定」を押してください。

### 5. メンバー追加・削除

「メンバー追加・削除」を押すと、次の項目を入力する画面が開きます。

| 項目 | 内容 |
|---|---|
| 新しく参加する人数 | 追加する人数を入れます。新しい人には、これまでの最後の番号の次から順に番号が付きます。 |
| 削除するメンバー | 抜ける人の番号にチェックを入れます。 |
| 復帰するメンバー | 一度抜けた人がいる場合だけ表示されます。戻る人の番号にチェックを入れます。 |
| ラウンド数 | 全体の合計ラウンド数です。増やすことだけできます。 |

「決定」を押すと、確定済みの行より下が新しいメンバーで作り直されます。「キャンセル」を押すと、何も変えずに閉じます。

- **番号は詰めません。** 3番が抜けても、4番は4番のままです。抜けた人の番号は欠番になります。
- **途中参加の人の試合数。** 新しく入った人は、その時点で残っているメンバーの平均試合数をすでにこなしたものとして扱います。追いつくために連続で出場し続けることはありません。
- **復帰した人の試合数。** 「自分の実績」と「復帰時点の平均」の大きいほうを持っているものとして扱います。
- **人数が足りなくなる場合。** 削除の結果、参加人数が面数×4 人を下回るとエラーになります。先に面数を減らしてください。
- **ラウンド数を増やす場合。** 増やした分のラウンドが表の下に追加されます。最後の行までチェックが入っているときは、ラウンド数を増やすと続きが作られます。増やさなければ、メンバーの変更だけが記録され、表は変わりません。
- **何も変えずに「決定」を押した場合。** 確定済みより下のラウンドを、同じ条件のまま別の案で組み直します。

### 6. 面数の変更

「面数」を押すと、面数(1〜3)を選ぶ画面が開きます。「決定」を押すと、確定済みの行より下が新しい面数で作り直されます。

- 参加人数が新しい面数×4 人に足りない場合はエラーになります。
- 確定済みの行は元の面数のまま残ります。表の列数は多いほうに合わせるので、面数が少ないラウンドのコート欄は空欄になります。

### 7. 偏りを確認する

表の下の「偏りのチェック」欄で、どのくらい均等に組めたかを確認できます。

- **同じ人とペアを組んだ回数**: 2人の組み合わせすべてについて、ペアを組んだ回数ごとに何組あるかを示します。`0回: 13組 / 1回: 32組` なら、「一度も組まない2人が13組、1回だけ組む2人が32組あり、2回以上組む2人はいない」という意味です。
- **同じ人と対戦した回数**: 同じ見方で、対戦相手になった回数を示します。
- **試合数・休み**: 番号ごとの出場回数と休みの回数です。

どちらの回数も、数字の幅が狭いほど均等です。

メンバーの出入りがあった場合、上の2つの回数は現在の参加者どうしだけで数えます。抜けた人の番号は薄い色で表示されます。途中参加の人は出場できるラウンドが少ないので、試合数が他の人より少なくなり、「0回」の組も増えます。

### 8. 全員分の内訳表を見る

いちばん下の「全員分の内訳表(ペア回数 / 対戦回数)」は、2人の組み合わせごとの回数をすべて並べた表です。縦と横に番号が並び、交わるマスに `ペアを組んだ回数/対戦した回数` が入っています。

| | 1 | 2 | 3 |
|---|---|---|---|
| **1** | | 1/2 | 0/1 |
| **2** | 1/2 | | 1/1 |
| **3** | 0/1 | 1/1 | |

この例では、1番と2番は「ペアを1回組み、相手として2回対戦する」、1番と3番は「ペアは組まず、相手として1回対戦する」と読みます。同じ番号どうしのマス(斜めの線上)は空欄です。表は斜めの線を挟んで対称なので、どちらの番号から引いても同じ値になります。

抜けた人の行と列は薄い色で表示されます。

### 9. 共有リンクで表を配る

「共有リンクをコピー」ボタンを押すと、今の表をまるごと含んだリンクがコピーされます。LINE やメールに貼り付けて送ると、受け取った人はリンクを開くだけで、同じ表を自分のスマホで見られます。

リンクに含まれるのは、組み合わせ、メンバーの出入り、リンクを作った時点のチェックです。表のデータはリンクの文字列そのものに入っているので、サーバーには何も送られません。そのぶんリンクは長くなります(10ラウンドで300文字ほど)。

- **変更したら送り直す。** リンクは作った時点の表です。そのあとで表を作り直したり、メンバー・面数・ラウンド数を変えたりしても、送り済みのリンクの中身は変わりません。もう一度「共有リンクをコピー」を押して、新しいリンクを送ってください。
- **チェックは同期されない。** リンクを開いたあとに付けたチェックは、その端末だけのものです。他の人の画面には反映されません。
- **同じリンクを開き直した場合。** その端末で付けたチェックはそのまま残ります。
- **別の表が保存されている端末で開いた場合。** 保存されている表を置き換えてよいかの確認が出ます。新しいリンクを受け取ったときは「OK」を押してください。キャンセルすると、元の表が残ります。
- **受け取った人も操作できる。** リンクから開いた表でも、メンバー追加・削除や面数の変更ができます。ただし、その結果は自分の端末にしか反映されません。変更は1人(幹事)が行い、そのつどリンクを送り直す運用をおすすめします。

## データの保存について

組み合わせ、チェックの状態、メンバーの出入りは、使っているブラウザの中に自動で保存されます。ページを再読み込みしたり、閉じて開き直したりしても、前回の表がそのまま表示されます。

- **保存のタイミング**: 「決定」で組み合わせを作ったとき、チェックを付け外ししたとき、メンバーや面数を変更したときです。
- **保存先**: ブラウザ内(localStorage)だけです。入力した内容や組み合わせがサーバーに送られることはありません。
- **自動では共有されない**: 保存は端末ごと・ブラウザごとです。他の人の端末や、自分の別の端末・別のブラウザには自動では引き継がれません。全員で同じ表を見るには、共有リンク(使い方の手順9)を送ってください。
- **消える場合**: シークレットウィンドウ(プライベートブラウズ)で使った場合や、ブラウザの閲覧データを消去した場合は残りません。
- **保存できる表は1つ**: 上の「決定」を押して作り直すと、前の表は上書きされます。

## アルゴリズム

### 評価値

「均等さ」を1つの数値で測り、それが小さくなる計画を探します。

```
評価値 = 3 × Σ(ペアを組んだ回数)² + 1 × Σ(対戦した回数)²
```

Σ は2人の組み合わせすべてについての合計です。

- **2乗する理由**: 同じ2人に回数が集中するほど値が大きくなります。たとえば「ある2人が2回、別の2人が0回」は 4+0=4、「どちらも1回ずつ」は 1+1=2 となり、ばらけているほうが良いと判定されます。
- **ペアの重みを3倍にする理由**: 同じ人と何度も組むほうが、同じ人と何度も当たるより偏りとして目立つためです。

完全に均等な組み合わせは、人数とラウンド数によっては存在しません。そのため、厳密な最適解ではなく、短時間で見つかる範囲でなるべく良い案を採用します。

### 手順

**1. 1ラウンドずつ順に組む(貪欲法)**

各ラウンドについて、次の2段階で決めます。

1. 出場者を選ぶ(面数×4 人)。試合数が少ない人を優先し、同数なら最後に出場してから長く休んでいる人を優先します。それでも同順位なら乱数で決めます。これにより、試合数の差が小さく収まり、休みが続きにくくなります。

   参加人数が「面数×4」のちょうど2倍以上の整数倍(1面なら8人・12人・16人…、2面なら16人・24人…)のときは、この選び方のままだと同じ顔ぶれが決まった順番で出続けてしまいます(下の「顔ぶれが固定されないための工夫」を参照)。その場合は、選んだあとで1人だけ入れ替えます。
2. 出場者をコートとペアに分ける。分け方をすべて調べ、それまでのラウンドとの重複が最も少ないものを選びます。同点の場合は乱数で決めます。

| 面数 | 分け方の総数 |
|---|---|
| 1面(4人) | 3 通り |
| 2面(8人) | 315 通り |
| 3面(12人) | 155,925 通り |

**2. 何度もやり直して最良の案を選ぶ**

貪欲法は先のラウンドを見越さないので、1回の結果は乱数次第でばらつきます。そこで、約1.2秒の間、組み直すことを繰り返し、評価値が最も小さい案を残します。試せる回数は条件によって変わり、1〜2面なら数千回以上、3面なら200回前後です。

### 途中で打ち切っても均等になるように

組み合わせ表のラウンドを最後まで消化せず、途中で打ち切ることはよくあります。このツールは、どのラウンドで打ち切っても、そこまでの均等さがなるべく保たれるように作っています。

手順1では、各ラウンドを「それまでのラウンドだけ」を見て組み立てます。後のラウンドで帳尻を合わせることを前提にしないので、どの時点で打ち切っても、その時点までの組み合わせは均等に近くなっています。

逆に、全ラウンドを通して出場者の位置を入れ替え、最後のラウンドを終えた時点の評価値をさらに下げる仕上げ(局所探索)は、あえて行っていません。この仕上げをすると、最後まで消化したときの均等さは少し良くなります。しかし、序盤の偏りを後半で埋め合わせるような組み方を許すことになるので、途中で打ち切ったときの均等さはかえって悪くなります。

### 顔ぶれが固定されないための工夫

参加人数が1ラウンドの出場人数(面数×4)のちょうど k 倍(k は2以上)のとき、全員の休みの間隔を完全にそろえると「k ラウンドに1回だけ出る」形になり、k ラウンドごとにまったく同じメンバーが出ることになります。たとえば1面・12人なら、4人ずつの3グループが順番に出るだけになり、残り8人とは一度も一緒にプレーしません。全員の休みの間隔をそろえることと、顔ぶれが固定されることは同じことなので、混ぜるにはだれかの休みの間隔を少しずらすしかありません。

そこで、この人数のときは自動で次の調整をします。

- 毎ラウンド、出る予定の人と休む予定の人を1人ずつ入れ替えます。入れ替えるのは試合数が同じ人どうしに限るので、試合数の差は変わりません。
- 入れ替えで休みが延びるのは1ラウンドまでです。連続休みの最長は、本来より1ラウンド長くなるだけです(1面・8人なら、2回続けて休む人が出ます)。
- 延びる役は、まだ延びたことのない人から順に回します。

この調整をしたときは、入力欄と組み合わせ表の間に、次のお知らせが表示されます。

> ※人数が面数×4の倍数のため、同じ顔ぶればかりにならないよう、一部の人の休みを不公平が出ないロジックで1ラウンド長くしています。

たとえば1面・12人・24ラウンドでは、調整なしだと同じペアが3回組む組が12組できますが、調整ありでは最多でも2回(2〜3組)になります。

### 途中変更のときの作り直し

メンバーや面数を変更したときも、上と同じ手順を使います。違うのは出発点だけです。

1. **確定済みの行を実績として読み込む。** 一番下のチェックの行までについて、だれとだれが何回ペアを組み、何回対戦したか、各自が何試合出たか、最後に出たのはどのラウンドかを集計します。チェックが飛んでいる行も、実施済みとして含めます。
2. **途中参加の人に「みなし試合数」を与える。** 新しく入る人には、その時点で残っているメンバーの平均試合数(小数のまま)を与えます。同時に抜ける人は平均の計算に含めません。復帰する人には、平均に届かない分だけを与えます。みなし試合数は出場者を選ぶ順位にだけ使い、画面に表示する試合数は実際に出た回数です。
3. **残りのラウンドだけを組む。** 実績を引き継いだ状態から、新しいメンバーと面数で手順1・2を実行します。評価値には確定済みの分も含まれるので、すでに組んだ相手や当たった相手は、残りのラウンドでは避けられます。

抜けた人が関わる回数は評価値に残りますが、その人はもう出場しないので、残りの組み方には影響しません。
